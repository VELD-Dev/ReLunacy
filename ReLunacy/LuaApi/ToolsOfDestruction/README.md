# Tools of Destruction — Lua API

Nothing is documented yet. See `../README.md` for the format.

What the shipped scripts show about the surface to be documented (generated by
`dev/tools/lcprobe --inventory`, which reports only observed facts):

- **437 global functions** are called. The heaviest are `wait`, `dc_set_tile`, `is_in_volume`,
  `obviate`, `unobviate`, `prt`. This is the bulk of the work.
- **28 handle types** are used as method receivers — `moby_handle`, `volume_handle`,
  `controller_handle`, `path_handle`, `pod_handle`, `area_handle` and others.
- **Only 5 distinct method names exist across all 35,486 method calls**: `new` (35,409, always one
  argument), `is_valid`, `get_first`, `get_next`, `get_handle`.

So the object surface is small and regular — the handle types are constructed as
`moby_handle:new(id)` and then passed to global functions. Documenting the 28 handle classes and
their `new` is a short, high-value first pass; the 437 globals are the long tail.

The argument counts in the worklist are what the call sites pass, which bounds a signature but does
not give it: parameter names, types, return shapes and meanings come from the EBOOT.
